# FinCausalAudit — code and data reproducibility archive

**This distribution deliberately contains NO LaTeX source, manuscript PDF, bibliography, or paper figures.** It keeps the experiment code, saved measurements, associated data and analysis corrections only. This is independent of whatever manuscript edits the authors have subsequently made.

## Primary study: v4 (used for the latest submission draft)

- **Notebook:** `code/notebooks/05_v4_main_colab.ipynb`
- **Raw complete *light* export:** `data/v4_full/` (CSV/JSON exports, benchmark cases, SEC inputs, per-job manifests and quality-gate records).
- **Design:** six model checkpoints, three dataset seeds, 18 model-seed jobs, 1,080 independent synthetic cases, 8 variants/case, 51,840 first-pass model evaluations.
- **Diagnostic findings reported in draft:** mean test-ID internal/text+output AUROC 0.928/0.765; unseen-template 0.742/0.642.
- **Causal reliability:** 18/18 preflight identity/null controls passed. This does *not* imply a general source-trust mechanism or prove that all specific edits are valid.
- **SEC:** 139 distinct task cases drawn from 70 issuer/period observations in 14 companies; exported SEC data are extracted financial numbers, not full filings.
- **SEC year issue:** the original prompts' year label is +2 relative to the year of the true period end. Model predictions were computed using the erroneous prompt; the v6 supporting `sec_period_labels_corrected.csv` repairs metadata **only** and does not repair or replace those model evaluations.

The v1–v3 folders provide provenance and sensitivity/negative-control context; **do not pool their outcomes with v4** as though all prompts and intervention protocols were identical. SmolLM2 is present in v2/v3 historical data, but was excluded from the v4 primary cohort. Historical records are preserved, rather than silently deleted.

## Reproduce paper-level statistics offline

With Python 3.10+ (recommend a fresh virtual environment):

```bash
python -m pip install -r environment/requirements_offline.txt
python scripts/check_integrity.py
python scripts/verify_v4_results.py
python scripts/recompute_v3_auroc.py
python scripts/correct_sec_metadata.py
```

These scripts work **without a GPU and without contacting the SEC**. They regenerate/check the key tabulated values and SEC year metadata from recorded CSV rows. Reported intervals, probe-fitting choices, causal edits and held-out evaluation were generated by the Colab notebooks; full reruns should use those notebooks.

## Re-execute the full GPU pipeline

1. Upload `code/notebooks/05_v4_main_colab.ipynb` to Google Colab and select an NVIDIA GPU (the original run used an L4).
2. Run the notebook's setup cell with dependencies indicated in `environment/requirements_colab_v4.txt`; **retain Colab's matching CUDA/PyTorch installation**.
3. Set `PROFILE = 'full'`, `USE_DRIVE = True`. Running from a new Drive folder avoids confusing archived datasets with new ones. Optional SEC extraction requires a legitimate identifying SEC User-Agent and network access.
4. Execute all cells, then compare the resulting exports to `data/v4_full/exports/full/` and each run's revision/seed in its `manifest.json`.
5. Reproduce historical sensitivity work with the v3 and v2 notebooks separately.

**External dependencies:** model weights, tokenizers and SEC public API are *not* bundled. Model checkpoint commit hashes, where recorded, are in `data/v4_full/jobs/**/manifest.json`. Torch/GPU kernel differences, Hugging Face model revisions, and changing SEC facts can affect exact bit-for-bit replication. The user-provided result exports were labelled `light` and **omit some intermediate activation tensors/caches** needed to resume the original session at an arbitrary internal step. Rerun the notebook to regenerate them.

**Data-use limits:** the synthetic labels are rule-defined, authority is *textually claimed* rather than authenticated, and extracted SEC facts should not be represented as complete reading of financial filings. Never treat probe error prediction as proof of a causal financial evidence-trust circuit.
